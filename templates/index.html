🩺 BP Predict

Hypertension Detection & Stage Classification

📋 About

ML-based tool using Random Forest trained on clinical data. Classifies into: Normal, Elevated, Stage 1, Stage 2.

🔬 Quick Test Values

Normal: Age 30, BMI 22, BP 110/70, Chol 160

Stage 1: Age 55, BMI 29, BP 135/85, Chol 210

Stage 2: Age 65, BMI 32, BP 155/95, Chol 240
